NOTES
═══════════════════════════════════════════════════════════════════════════════

- Lowercase package names - PEP 8 standard, works everywhere
- '__init__.py' - This informs python that the directory is a package (a structured collection of modules meant to work together)
- Why use venv:
    - Isolated environment per project
    - No package conflicts
    - Clean, reproducible setup

- Why pyproject.toml (not setup.py):
    - Modern standard (PEP 518)
    - One file for everything
    - No deprecation warnings

- What happens when 'pip install -e .'
    1. Reads pyproject.toml
    2. Finds all packages (directories with __init__.py)
    3. Installs dependencies
    4. Creates editable install (changes apply immediately)
    5. Adds package to Python's import path
